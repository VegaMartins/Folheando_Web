Folheando

Uma estante de livros feita com HTML, CSS e JavaScript puro.

Projeto inspirado no meu app Folheando em Flutter, refeito para a web para praticar os conceitos iniciais de JavaScript.

Funcionalidades
Estante com prateleiras
Busca por título ou autor
Abas: Todos, Lendo, Quero ler, Lidos e Favoritos
Nota com estrelas, review e favoritos
Adicionar e remover livros
Dados salvos no navegador (localStorage)

Conceitos de JavaScript praticados

Objetos, arrays, funções, condicionais, laços, filter, manipulação do DOM, eventos, localStorage e JSON.
